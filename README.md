# hackbase

Zero-dependency starter kit for open-weight AI hack day projects. Pure Python standard library.

- `hackbase.client`: chat with Ollama or any OpenAI-compatible endpoint, with image input.
- `hackbase.skills`: load `SKILL.md` folders (name and description frontmatter).
- `hackbase.agent`: tool-calling loop.
- `hackbase.web`: one-page chat UI served by `http.server`.
- `hackbase.cli`: `hackbase chat`, `run`, `skills`, `serve`.

See `docs/PROBLEMS.md` for the problem statements this base is built to serve.
