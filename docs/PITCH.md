# Two-minute demo outline

The Hack Day asks for a live demo of working code, no slide-only pitches, in two minutes. Practise this shape once.

| Time | Say | Show |
|---|---|---|
| 0:00 to 0:15 | One sentence: who has the problem and what it costs them. | Nothing yet, or a photo of the real situation. |
| 0:15 to 0:30 | "Open model, running here, no cloud." Name the model and the machine. | `tinyharness doctor` output or the GPU load in `nvidia-smi`. |
| 0:30 to 1:30 | The one thing that works. Use a real input from the room, not a prepared one. | The live run. Keep the terminal font large. |
| 1:30 to 1:50 | Why open matters here: private data stays local, works offline, no price or policy change can switch it off. | Unplug the network or run with `--offline`. |
| 1:50 to 2:00 | What you would build next and where the repo is. | The public repository URL. |

Checklist before the demo:

1. Run the demo once with `--offline` so nothing depends on venue WiFi.
2. Have the repository public, with the licence file, before the submission freeze.
3. Keep one backup recording of the demo working.
4. Name the model, the engine and the machine out loud; judges look for open-weight AI doing real work.
