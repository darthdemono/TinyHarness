# Problem statements

Theme: **AI belongs to everyone**. Build something new with open-source or open-weight AI doing real work.
Prize tracks: Best Use of Gemma 4 (multimodal, focused tools, rapid prototyping) and Best Open-Source AI Project
(agent skill, open-weight model, model harness). Each statement lists the hackbase parts it reuses.

| # | Problem statement | Track fit | hackbase parts |
|---|---|---|---|
| 1 | Plain-language explainer for official letters (visa, residence permit, bank, university) that runs fully offline so private documents never leave the laptop. | Focused AI Tools | chat, images, skills |
| 2 | Photo to action: point a camera at a bus stop sign, medicine box or menu in a foreign language and get a spoken-style answer in your own language. | Multimodal Experience | chat with images, web UI |
| 3 | Agent skill pack that teaches any assistant a local community's workflow (student union, food bank, repair cafe) as a standard SKILL.md folder. | Open-Source AI, agent skill | skills loader |
| 4 | Study buddy that turns lecture slides or notes into quizzes with worked, step by step answers, local model only. | Focused AI Tools | chat, skills, tools |
| 5 | Accessibility describer: image to alt text and short audio-friendly description for blind or low-vision users, running on a cheap laptop. | Multimodal Experience | chat with images |
| 6 | Tiny model harness: a clean tool-calling loop that works with any open-weight model, including ones with no native tool support. | Open-Source AI, model harness | agent loop |
| 7 | Offline first-aid and emergency guide in plain language, with a retrieval step over a small trusted text folder. | Focused AI Tools | tools, skills |
| 8 | Repo helper for new open-source contributors: reads a repository and writes a good-first-issue map and setup guide. | Rapid Prototyping | tools (file read), agent loop |
| 9 | Open-weight model comparison bench: same prompts, several local models, side by side latency and answers in a web page. | Open-Source AI, open-weight model | chat backends, web UI |
| 10 | Language practice partner that corrects short messages and explains each mistake, tuned for low-resource languages. | Focused AI Tools | chat, skills |
| 11 | Receipt and invoice reader: photo to a clean table you own, with no cloud upload. | Multimodal Experience | chat with images, tools |
| 12 | Community notice board summariser: long group-chat exports to a short weekly digest per language. | Rapid Prototyping | chat, tools, skills |
| 13 | Prompt-injection tester: a skill that attacks your own agent with known tricks and reports which ones worked. | Open-Source AI, agent skill | skills, agent loop |
| 14 | Kids' science tutor that answers from a fixed local textbook and refuses to guess outside it. | Focused AI Tools | tools, skills |

These are ideas generated from the published themes, not organiser requirements. Pick one in the first
fifteen minutes; the base already covers the plumbing for all of them.
