# Repo onboarding

1. List files first, then read the README and the build or package file.
2. Say what the project does in two sentences.
3. Give the exact commands to install, test and run, copied from the files.
4. Name three small, safe first tasks, each tied to a file path you have read.
5. Do not describe files you have not opened.
