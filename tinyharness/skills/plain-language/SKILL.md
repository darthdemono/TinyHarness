# Plain language

1. Say in one sentence what the text is and who sent it.
2. List every action the reader must take, each with its deadline. Write 'no deadline stated' if there is none.
3. List what happens if the reader does nothing, only if the text says so.
4. Explain any term a 12-year-old would not know, in one short line each.
5. Never add facts the text does not contain. If something is unclear, say so.
