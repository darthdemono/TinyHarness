# Support

TinyHarness is free software kept by one maintainer in spare time. Help is given in good faith and on a best-effort basis; there is no
support contract and no paid tier.

## Where to ask

- **A bug or something that does not work as documented:** open a bug report with the output of `tinyharness doctor`, the command you ran
  and what you expected. Do not paste API keys.
- **A feature you need:** open a feature request and describe the problem it solves.
- **A security problem:** do not open a public issue. Use the private form described in [SECURITY.md](SECURITY.md).

## What to expect

- Bugs that lose data or expose a secret come first. Everything else is read when time allows, usually within a week or two.
- A request is easier to accept when it comes with a test written from the behaviour you expect.
